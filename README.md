# 🎓 通用技术研学与框架深潜模板 (Study Template)

> 这是一个专为硬核开发者打造的**技术研学、源码深潜与框架啃透模板**。  
> 告别死记硬背与走马观花，内置专属 AI 私教（老王），通过**「动机穿透、源码溯源、全量事实核对矩阵、老王灵魂盘问」**四步法，将哪怕是 AI 生成的生涩课件，也彻底转化为属于你自己的肌肉记忆与高质量技术资产。

👉 **[点击查阅：📖 研学模板完全使用指南 (USAGE.md)](./USAGE.md)**（包含：全流程图、黄金 Prompt 清单、实操沙盒跑法、老王技术盘问、一键产出博客与面试卡指南）

## 💡 为什么需要这个模板？

1. **避免污染主工程**：面试题库（如 `ai-learn`）只管高频八股与面试战术，业务工程（如 `ai-agent-platform`）只管核心业务。研学项目需要独立跑环境、装依赖、造报错、写实验代码，必须**环境隔离**！
2. **专治 AI 生成课件**：现在的技术课件和文档很多充斥着抽象名词和车轱辘话。本模板内置的 `study-coach` 能将其暴力拆解为**大白话直觉模型**，同时用**全量技术事实清单**保证细节零遗漏。
3. **一鱼多吃、高价值产出**：不仅学懂代码，学完后自动提炼出**面试真题卡（对齐 ai-learn）**、**交互式架构图 (/archify)** 与**多平台技术博客底稿（知乎/掘金/小红书/CSDN）**。

## 🚀 极速上手：三步开启一次新框架研学

### 第一步：复制本模板，创建独立研学项目
```bash
# 例如我们要学习 Pi Agent 框架：
cp -r /Users/lijiaxin/PyCharmMiscProject/ai-research/ai-study-template /Users/lijiaxin/PyCharmMiscProject/ai-research/pi-agent-study
cd /Users/lijiaxin/PyCharmMiscProject/ai-research/pi-agent-study
```

### 第二步：丢入学习材料
把你的课件（Jupyter Notebook、Markdown、PDF、配套实战代码 zip）丢进 `01-resources/raw/`：
```bash
cp -r /path/to/your-courseware/* 01-resources/raw/
```

### 第三步：呼唤老王开学！
在项目终端或聊天框中对 Agent 发号施令：
- **解析资料生成大纲**：「老王，解析一下 01-resources/raw/ 里的课件，生成学习大纲！」
- **开始第一章人话学习**：「带我啃第一章！穿透动机，不要讲虚的，顺便把核心事实矩阵列出来。」
- **实验与故障注入**：「在 02-labs 给我写一个最小验证 Demo，并故意改错一个参数让我排障。」
- **章节验收盘问**：「第一章我看完了，出 3 道硬核追问考考我！」
- **提炼成果与输出博客**：「把这次学的内容提炼成面试卡，并生成一篇掘金/知乎长文底稿！」

## 🗂️ 目录导览

|---|---|---|
| `01-resources/` | **【料】学习原料库** | 原始课件存 `raw/`，自动提炼的大纲存 `syllabus.md` |

## 🎯 学习终局验收标准（四级达标线）

- **Level 1（人话讲透）**：能用生活/工程隐喻，向非本框架开发者讲清核心原理与取舍。
- **Level 2（肌肉记忆）**：脱离课件文档，5 分钟内能手撕最小跑通 Demo 或扩展插件。
- **Level 3（无惧盘问）**：通过老王 3 道致命连环拷问，说清异常边界与底层源码调用流。
- **Level 4（资产闭环）**：完成一鱼多吃——产出 1 篇深度实战长文，沉淀 2~3 道面试真题入库。
