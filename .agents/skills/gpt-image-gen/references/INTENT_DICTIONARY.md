### 📱 social-media — 社媒界面·截图·内容卡

**触发关键词：**
`截图` `小红书` `朋友圈` `微博` `抖音` `X` `Twitter` `Instagram` `社媒` `界面` `封面图` `直播` `评论区` `互动数据` `推文` `发帖` `内容卡` `公众号` `手机截图` `galgame` `UI仿造`

**策略规则：**

### 🎨 art-illustration — 艺术插画·奇幻·概念艺术

**触发关键词：**
`插画` `奇幻` `水彩` `油画` `国画` `水墨` `工笔` `刺绣` `概念艺术` `艺术创作` `唯美` `星空` `梦幻` `诗意` `剪影` `双重曝光` `光影` `天空之镜` `宏大场景` `风格参考`

**策略规则：**
- **人物+环境融合**：先描述人物（外貌+服饰+动作），再描述环境（光源+色调+氛围），最后点风格
- **光影是灵魂**：必须指定光源位置、色温（冷/暖）、光的质感（柔光/硬光/逆光/环境光）
- **公式**：`[主体] + [具体特征/动作] + [环境/位置] + [艺术风格/材质] + [光影/色调] + [负向约束]`

**懒加载指令：** 读取 `references/cases/art-illustration.md`。

### 🃏 ip-collectibles — IP卡牌·游戏·收藏品·联名

**策略规则：**

- **角色一致性**：同一 IP 的多张卡需共享相同的艺术风格指令前缀

**策略规则：**

### 📖 comic-narrative — 漫画·条漫·叙事分镜

**触发关键词：**
`漫画` `条漫` `分镜` `多格` `故事` `叙事` `对话气泡` `剧情` `场景` `搞笑` `梗图` `comic` `strip` `格漫` `3格` `4格`

**策略规则：**
- **格数限制**：单张图最多 4 格，超过必须拆分
- **对话气泡**：所有台词用反引号包裹，并绑定到具体角色和格子位置
- **叙事节奏**：描述每一格的场景（背景+人物状态+台词），格与格之间有时间跳跃

**懒加载指令：** 读取 `references/cases/comic-narrative.md`。

### ✨ creative-special — 创意特殊·字体海报·双重曝光

**触发关键词：**
`字体设计` `概念字体` `双重曝光` `剪影填充` `水墨双重` `创意合成` `实验性` `抽象` `装置艺术` `视觉诗` `文字海报` `锁屏壁纸` `叠层合成`

**策略规则：**
- **双重曝光**：明确主体轮廓（人脸/动物/物品）+ 填充内容（场景/纹理/插画）+ 融合方式（柔和/锐利）
- **字体海报**：文字造型 + 材质质感 + 背景关系 + 色彩层次，文字本身用反引号包裹
- **即兴模式优先**：此类无固定模板，直接用自然语言模式合成提示词

**懒加载指令：** 读取 `references/cases/creative-special.md`。

### 🖊️ image-editing — 图像编辑·局部修改·风格迁移

**触发关键词：**
`修改` `调整` `只改` `保留` `局部` `替换` `风格迁移` `换装` `换背景` `移除` `删掉` `抠图` `去掉` `加上` `改成` `草图转渲染` `sketch to render` `inpainting` `outpainting` `edit` `style transfer`

**策略规则：**
- **核心范式**：「控制变化范围」而非「重新生成」，只改要改的，锁死其他
- **必须重申保留锚点**：每次编辑提示词都要显式列出「保留不变的内容清单」
- **7大编辑公式**：详见 SKILL.md「图像编辑范式」章节

**场景子类路由：**
| 用户意图 | 对应公式 |
|---|---|
| 「改成X风格」 | 风格迁移：保留构图/光源，只换画风 |
| 「只改X部分」 | 局部修改：明确声明其他一切不动 |
| 「换衣服/道具」 | 虚拟换装：锁定面部/体型/姿势 |
| 「草图变渲染」 | 草图渲染：保留布局/透视，加材质/光照 |
| 「去掉/删掉X」 | 对象移除：seamless fill，不改其他 |
| 「把X移到Y」 | 主体迁移：锁定外观，匹配新环境光照 |
| 「抠图」 | 产品抠图：clean edges，no white fringe |

**不适用懒加载**：直接读取 SKILL.md「图像编辑范式」章节的完整公式。

### 🎭 character-consistency — 角色一致性·故事板·连续剧

**触发关键词：**
`同一个角色` `保持角色` `人物一致` `故事板` `连续剧` `漫画系列` `分集` `下一集` `续集` `第N话` `character sheet` `角色设定` `故事续写` `角色参考` `系列图角色统一`

**策略规则：**
- **两步工作流**：先生成「角色锚点图」，再进行「故事续写」
- **每次续写必须完整重复角色描述**，不能只说「保持和上一张一样」
- **精确服装描述**：不要模糊词（「蓝外套」→「深海蓝单排扣羊毛大衣」）
- **风格前置锁定**：系列图开头声明「统一艺术指导：[风格]」

**不适用懒加载**：直接读取 SKILL.md「角色一致性工作流」章节的完整操作流程。

## 快速路由决策树

```
用户说"生成一张图" → 
  ├─ 含流程/步骤/对比/知识点？ → infographic-edu
  ├─ 含截图/界面/小红书/推文？ → social-media  
  ├─ 含海报/品牌/国潮/城市？   → brand-poster
  ├─ 含插画/奇幻/水彩/唯美？   → art-illustration
  ├─ 含写真/摄影/真人/明星？   → character-portrait
  ├─ 含卡牌/游戏/IP/收藏？     → ip-collectibles
  ├─ 含爆炸图/拆解/硬件/架构？ → tech-hardware
  ├─ 含漫画/条漫/分镜/格漫？   → comic-narrative
  ├─ 含双重曝光/字体/抽象？    → creative-special
  ├─ 含修改/只改/替换/移除/换装/风格迁移？ → image-editing ⭐️新
  ├─ 含同一角色/故事续写/角色一致？       → character-consistency ⭐️新
  └─ 以上都不明确 → 询问用户意图，展示 Protocol A 模板目录
```
