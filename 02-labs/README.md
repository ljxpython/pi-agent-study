# 02-labs 实操实验沙盒

## 说明
**学框架不敲代码、不造报错就是耍流氓！**
这里是你的代码练手操练场，与外部项目环境彻底隔离。

- `playground/`：随手测试代码、临时脚本验证、一次性探索 Demo。
- `milestones/`：按章节/里程碑组织的正式实践代码（如 `m1-basics/`、`m2-extensions/`）。

## 核心原则
1. **亲手敲过才算数**：不要只在课件 Notebook 点运行，把代码抽出来跑独立脚本。
2. **主动制造故障**：让 Agent 故意把某个关键入参、接口字段改错，观察控制台真实报错，并在 `03-notes/debug-log.md` 记录解决过程。
