## 解压与使用

将压缩包解压到本目录，保留它自带的 `学员扩展资源包-20260918` 文件夹名称，让该文件夹与完整课件处于同一级。课件中指向资源包的相对链接才能正常打开。

在本目录打开终端，进入资源包：

```bash
cd ./学员扩展资源包-20260918
```

先阅读资源包内的 `README.md`，再按操作稿相应章节执行。操作稿要求切换目录时，先确认当前目录；不要把终端命令与 Pi 对话提示词混在一起执行。第四章从模板创建自己的工单项目，不使用他人已经运行过的练习目录。

扩展安装包不等于全部运行依赖已经安装。Node.js、Pi、模型服务与凭据，以及各案例需要的依赖，仍需按文档在自己的电脑上准备。

第五章先使用操作稿 U0 的资源包内入口。U1、U2 是原课程项目的历史验证记录，其路径与环境没有纳入这个精简资源包；U3 是待实现要求，不能当作现成可运行案例。
