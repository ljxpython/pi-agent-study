# Pi 工单问答助手｜学员版

这是一个本机运行的 Pi Agent 工单练习项目：前端负责资料上传、对话和成果展示；后端通过 Pi SDK 管理会话，调用受控工单工具，并在用户确认后保存 Markdown 报告。交付包包含运行源码和练习资料，不包含对话历史、已上传资料、模型密钥或已生成报告。

## 运行前准备

- 安装 **Node.js 22.19.0 或更高版本**，并确认终端中的 `node -v`、`npm -v` 可运行。
- 首次执行 `npm ci` 需要能访问 npm 软件包源。
- 准备一个自己可用的模型 API。模型在网页的“设置”里配置；**启动前不用修改配置文件，也不用把 API Key 写进项目文件**。如果本机已有可用的 Pi 模型配置，也可以在设置里选“本机 Pi 配置”。
- 端口 **5179** 须空闲。本项目只监听本机 `127.0.0.1`，不会自动向局域网开放。

## 第一次启动

解压后打开终端，进入这个 `Pi工单问答助手-学员版` 文件夹，依次执行：

```sh
cd frontend
npm ci
npm run build
cd ../backend
npm ci
npm start
```

看到 `Pi 工单问答助手：http://127.0.0.1:5179` 后，在浏览器打开 **http://127.0.0.1:5179/**。保持运行后端的终端开启；结束时在该终端按 `Ctrl+C`。以后再次使用，只需在 `backend` 目录执行 `npm start`；修改前端源码后，先重新执行 `frontend` 目录的 `npm run build`。

`frontend` 自己的开发端口不是本项目的交付入口。上述启动方式由后端在 **5179** 同时提供网页和 API，因此不用另开前端开发服务器。

后端请使用上面的 `npm start`；直接执行 `backend/dist/` 中的编译文件不是本包支持的启动方式。

## 在网页里配置模型

1. 点击页面右上角的**“设置”**。
2. 如果没有现成的 Pi 本机模型配置，选择**“独立配置”**；根据你使用的模型服务商说明，填写 `Provider`、`接口类型`、`Base URL`、`模型 ID` 和 `API Key`。接口类型要与服务商实际提供的协议一致；不要把某个模型名称当作通用接口地址。
3. 点击**“保存设置”**，再分别运行**“问答测试”**和**“工具调用测试”**，检查它们的最终结果。保存成功只表示配置被接受，不能代替真实调用成功。

独立配置的 API Key **仅保存在当前后端进程内存**，不写入项目文件，也不会在页面回显。刷新网页不会清掉进程内密钥；重启后端后需要重新输入。项目会保留非密钥的模型选择，因此重启后看到原模型名称，也不代表密钥仍可用。本机 Pi 配置模式仅在本机已有相应模型和认证时才可用，学员不需要预先配置它。

## 完成一条工单练习

1. 首次启动会自动生成内置的**“示例工单.json”**。在左栏点击它的**“添加”**，确认输入框上方显示该资料名称。点击资料名称只是看详情，不等于绑定。
2. 点击“查询工单 `/query`”建议，或在输入框单独输入 `/query`，再点**“发送问题”**或按 Enter。建议按钮只填入命令；不要在斜杠命令后追加参数。
3. 查看中间的**“工具调用”**和右侧**“查询结果”**。括号中的数字是本轮工具调用次数。内置示例中，平台团队的 `open` 工单应为 **T01、T04、T06，共 3 条**；核对右侧来源仍是当前资料。若模型提问而未实际调用工具，以实际工具记录和结果为准。
4. 保持同一份资料及本次查询结果，单独发送 `/report`。这一步应先产生**报告草稿**：右侧切到“报告”，显示“草稿待确认”。生成草稿尚未保存文件。
5. 阅读草稿后点击**“预览并确认”**，在弹窗里点**“确认保存”**。待页面出现“文件已保存”且“已保存报告”数量增加，再展开该报告，点击**“下载 Markdown”**。如需检查取消分支，可先在确认弹窗点“取消”，确认没有新增报告，再重新发送 `/report` 生成新草稿。

需要练习资料切换时，可以上传 `samples/` 里的 JSON：上传确认后，还需从左栏点击新资料的“添加”，再查询。`U01` 适合核对来源切换，`U02` 包含不同团队和状态，`U03` 全是已关闭工单，`U04` 用于练习补齐时效规则。切换资料后应重新查询，旧结果不能当作新资料的事实。

## 文件与数据位置

| 位置 | 内容 |
|---|---|
| `frontend/src/` | 网页源码 |
| `backend/src/` | 后端、会话、工单和报告逻辑 |
| `backend/resources/` | 两个提示词模板、分诊 Skill、注册工具的 Extension |
| `samples/` | 四份可手动上传的练习 JSON；不会在启动时自动上传 |
| `backend/data/` | **首次运行后才生成**的本机数据，包括对话、上传资料和已保存报告 |

确认保存的报告位于 `backend/data/reports/<报告ID>/report.md`，网页下载的文件名为 `report-<报告ID>.md`。`backend/data/` 属于每位使用者自己的运行数据，不是课程交付源码；再次分享项目时不要把它打包进去。

## 常见问题

- **网页打不开或提示后端未连接**：确认 `npm start` 仍在运行，地址是 `http://127.0.0.1:5179/`，并检查终端错误。5179 被其他程序占用时，先关闭占用该端口的程序再启动。
- **网页能打开但不能提问**：先在设置里完成模型配置，并分别查看问答与工具调用测试的最终状态；独立配置模式下，重启后端需要重新输入 API Key。
- **查询结果不是刚上传的资料**：上传后还要在左栏点击“添加”，核对输入区资料名称，再发送新请求。
- **没有报告确认按钮**：先完成当前资料的查询；发送 `/report` 后等请求结束，检查“工具调用”里是否成功出现“准备报告草稿”。只有右侧出现“草稿待确认”时，才会显示“预览并确认”。
- **报告已生成但找不到下载按钮**：切到右侧“报告”，展开“已保存报告”下面的报告标题，按钮在展开内容里。

本 README 描述的是项目源码的本机启动方式。真实模型调用的成功率与费用取决于学员自己的模型服务和配置；页面启动成功不等于模型业务调用通过。
