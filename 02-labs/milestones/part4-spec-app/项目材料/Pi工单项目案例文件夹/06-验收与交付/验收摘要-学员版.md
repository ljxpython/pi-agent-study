# 工单问答助手｜验收摘要与边界

本页依据原项目截至 2026-09-24 的验收记录整理，只说明**源工程当时**的证据层。随课源码是独立分发副本，不能继承源工程的测试通过结论；请按[学员版运行说明](../../../Pi工单问答助手-学员版/README.md)及课堂第五章的练习要求自行复验。

| 证据层 | 原项目记录过什么 | 不能据此推出什么 |
|---|---|---|
| 文档与 Spec | 需求、前端与后端合同、正常和失败条件 | 代码已经按新合同运行 |
| 工程检查 | 源工程的类型检查、构建和单元测试；2026-09-24 一轮记录为后端 79/79、前端 34/34 | 随课副本、学员机器或真实模型业务全部通过 |
| 浏览器与本机链路 | 来源切换、Tool 记录、报告确认/取消、回读及部分恢复路径有本机记录 | 每种异常、跨平台与断电场景已覆盖 |
| 真实模型 | 原工程完成过模型问答与工具调用；也记录过连接错误和人工重试 | 单次课堂演示稳定、底层权重身份可由回复自述证明 |
| 学员与课堂 | 尚无本包的学员独立操作、真人计时和课堂理解证据 | 可宣布课程交付已验收 |

学员可按一条用户任务记录五处证据：**独立预期 → 本轮资料身份与 Tool 输入 → Tool 返回记录和来源 → 页面是否显示本轮结果 → 如有写入，用户确认与文件回读**。成功空结果与上传错误、Tool 未调用、Tool 失败要分别写。发现第一处失配后修复负责的层，再用同一预期重跑；没有亲自跑到的步骤写“未验证”。

原始截图、探针 JSON、模型回执和失败日志仍在原项目验收目录，不作为本页的学员运行证明。实际分发前仍需从此包完成本机安装、模型配置与对应用户路径检查。
