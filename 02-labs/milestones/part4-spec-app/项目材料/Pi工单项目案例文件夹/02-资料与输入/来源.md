# 输入来源与使用边界｜学员版

本项目使用**构造的教学工单**，不接入企业生产数据。随课源码的 [samples](../../../Pi工单问答助手-学员版/samples/) 提供 U01—U04 练习资料；第五章上传使用其中的[U01 样本](../../../Pi工单问答助手-学员版/samples/直播演示样本-U01.json)。上传成功、选择资料和本轮 Tool 使用是三件不同的事，查询要核对资料身份、版本、记录与来源。

本目录完整保留原项目现存的 **39 张图片**：其中[决策过程图集](./决策过程图集/00-阶段索引.md)按八个阶段串起最初流程、采纳与否决的视觉方向、能力库、资料侧栏和工作台布局；[阶段 08 图文记录](./决策过程图集/08-工作台边框与对话布局/00-阶段记录.md)逐轮写明问题、用户反馈、合成基准与 Spec 条款。[视觉基线](./视觉基线/05-整体边框与对话交互合成基准.png)及 M1c 设计参考图保留在原有位置。生成图、用户反馈截图和实际页面截图的证据性质，以图集索引的说明为准。

图集和视觉基线中的 JSON 保存原项目的图片来源、说明及哈希；其中指向制作目录的来源路径是**历史溯源记录**，不作为本分发包的打开入口。练习用 U01—U04 只从随课源码的 `samples/` 取用，避免再发一份相同用途的样本。

视觉决策来自项目的生成图与页面反馈。这里保留了供 Spec 理解的[整体边框与对话合成基准](./视觉基线/05-整体边框与对话交互合成基准.png)、[模板管理参考图](./M1c设计参考/02-模板管理.png)和[命令菜单参考图](./M1c设计参考/04-命令菜单.png)。采纳与否决的浅色、深青工作台生成图可在[八阶段决策过程图集](./决策过程图集/00-阶段索引.md)中对照。生成图只约束设计方向，不证明模型连接、工单查询或保存已运行成功。

本目录已保留原项目现存的完整编号决策图集、历史来源哈希和图集收录的中间浏览器截图。学员需要判断当前页面是否符合设计，应以随课源码的实际页面和现行 Spec 核对。
