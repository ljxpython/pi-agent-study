# 第四课｜一页练习证据卡

课上填写第二、三、四、五章的判断：第二章写需求与 Spec 条件，第三章找接线和来源绑定，第四章划分职责，第五章先写预期并判读给定画面；未亲自运行的实际结果写“未验证”。第六章圈出交接缺项并写迁移判断。课后补齐完整运行结果与交接信息。只写自己实际运行或看到的内容，老师的演示结果不能填作自己的实测。

## 课后补齐后提交

- **本人改动**：新增验证文件与位置________；改动前后差异________；产品源码是否保持原样________。
- **人工确认与恢复**：Agent 何时给出待确认草稿________；取消后新文件数________；确认后新文件数________；刷新后能否回读________；同一数据目录重启后能否回读________；重启后旧待确认动作是否失效________。每项未做的分别写“未验证”。
- **接手入口**：项目文件清单________；Node 版本________；所用锁文件________；运行目录与命令________；模型配置和问答／工具测试结果________；失败应停在________。
- **仍未验证**：________。下一位接手者可以用________动作复核我的结果。

交付前自查：每个“通过”旁边都有本次命令、请求/资料来源或文件证据；演示截图与自己的运行记录分开；没有把函数测试或旧离线彩排写成自己的真实模型验证。
