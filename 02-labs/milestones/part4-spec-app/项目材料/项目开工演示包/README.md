# 第四课第二章｜项目开工演示包

这是一份可复制的起始文件夹：`AGENTS.md` 是项目 Agent 约定，`00-项目入口.md` 指向现行材料，`docs/方法/` 已放入工程规范、[大型项目防返工开工范式](./docs/方法/大型项目防返工开工范式.md)和[企业级 SPEC 驱动开发全周期 SOP](./docs/方法/企业级SPEC驱动开发全周期SOP.md)。开工先用防返工范式识别风险与裁剪范围；编写 Spec、实施和验收时再按风险使用 SOP。`docs/需求/`、`docs/设计/` 和 `docs/规格/` 只是后续文档位置；当前没有需求文档、设计文档或 Spec。

## 课堂怎样使用

1. 把整个 `项目开工演示包/` 复制到你选定的工作区，命名为自己的项目文件夹；在复制品根目录启动开发 Agent。演示产生的文件写在复制品里，保留这份原始材料供下次复用。
2. 按课堂口述演示先做“读取与追问”。要求 Agent 复述适用约束，提出会改变设计或验收的关键问题；这一轮不生成需求和设计。
3. 讲师以工单交接案例口述自己的回答并确认需求范围，再口述“生成需求文档”。检查文档是否区分已确认决定、示例样本和待确认项。
4. 需求文档经讲师确认后，再口述“生成设计文档”。检查前后端职责、资料来源、受控 Tool 与报告人工确认是否能回链需求。阶段 Spec 等后续对应阶段再建。

这套开工示例不等于已有工单助手工程的真实初始目录。课堂使用的是构造工单和教学决策，不能把已有工程的测试通过或真实模型结果写成这个新目录的实测。

两份新增方法是知识库原文快照，其中的本机归档路径属于出处信息；在学员复制的项目中，按本包 `00-项目入口.md` 的链接读取方法正文。

## 开工前可核对

- 项目根目录有 `AGENTS.md` 与 `00-项目入口.md`。
- 三份方法文档均位于 `docs/方法/`。先读工程规范与防返工范式适用章节；SOP 按阶段使用，不要求这次课堂演示一次写全平台项目的七件套或企业级完整合同。
- `docs/需求/`、`docs/设计/`、`docs/规格/` 目前不含业务文档。
